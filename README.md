# 購屋紅綠燈：中和區預售屋試行版

搜尋中和區已有公開成交紀錄的預售建案，輸入房屋坪數與每坪開價，再從候選清單加入至少三個不同建案，查看紅黃綠燈與各案成交基準。

頁面下方也可自行建立「我的建案觀察列表」。每個建案顯示最新一筆成交單價與日期、近三年平均成交單價／總價／房屋坪數，以及便宜、合理、昂貴三個參考價。列表保存在目前瀏覽器的 Local Storage。

第三頁簽「AI 趨勢分析」可選建案，檢視近三年各年度成交單價中位數與官方捷運工程線索。年度變動僅在兩個年度各有至少 5 筆成交時顯示。本站沒有建案經緯度，捷運線索只以同路名篩選，不表示實際距離、通車時程或未來漲幅。沒有 LLM 摘要時仍會顯示資料摘要；頁面不會直接呼叫 LLM，也不會暴露 API 金鑰。

此頁另有 13 項「未來增值潛力評估」檢查表：第 1 項嫌惡設施及地質安全是一票否決的先決條件；第 2–13 項依使用者優先順序設定為 18、12、9、9、8、8、8、7、6、5、5、5 分，合計 100 分。每個建案的回答只儲存在目前瀏覽器。安全項未確認通過、或已查核權重少於 70% 時不顯示單一分數，而呈現可能範圍。即使顯示分數，也只是主觀條件的加權清單，**不是房價漲幅、報酬率或已由 AI 驗證的預測**；捷運同路段線索不會自動判定為符合。

## 啟動

此版會讀取專案內的官方資料快照，需要透過本機網頁伺服器開啟：

```bash
python3 -m http.server 8000
```

前往 http://localhost:8000 。不需要安裝前端套件或設定 API Key。輸入的開價不會上傳到伺服器。

## 資料來源與更新

資料來源為[新北市政府地政局「不動產實價登錄資訊－預售屋案件」](https://data.ntpc.gov.tw/datasets/9238ccc2-9701-4ca7-a0a0-ebe4a0669685)。`data/zhonghe-presale.json` 是自官方 CSV 產生的靜態快照；網站不會自行更新。快照記錄產生日期與最新成交日期，畫面也會顯示。

更新步驟：

```bash
curl -L --fail 'https://data.ntpc.gov.tw/api/datasets/9238ccc2-9701-4ca7-a0a0-ebe4a0669685/csv/file' -o /tmp/ntpc-presale.csv
python3 scripts/update-data.py /tmp/ntpc-presale.csv
node --test
```

整理程序只保留中和區、住宅大樓與華廈的住家用預售屋交易，並排除解約、含特殊備註或缺少重要欄位的紀錄。政府原始檔仍是最終查核依據。若資料更新後欲發布，請先檢查交易數量與最新成交日期，再提交新快照。

## 判讀規則

1. 候選建案必須與目標建案類型相同，首次公開成交年份相差不超過使用者設定的 **1、2 或 3 年**。預售屋尚無實際屋齡，首次成交年份僅作為案齡代理值，並非完工年份。
2. 只納入**不含車位的房屋坪數**相差不超過 25%、近三年內成交的案例，每個建案最多取最近 30 筆。候選清單把同一路名排在前面，也會列出符合條件的中和區其他路段建案。
3. 使用者需加入至少 **3 個不同建案**才會亮燈。先算每案成交單價中位數，再取各案中位數的中位數，讓每案只占一票。開價低於基準是綠燈；基準至高出 15% 是黃燈；高出超過 15% 是紅燈。

房屋坪數與開價都應排除車位。官方每坪單價使用資料中的單價欄位，並從元／平方公尺轉為萬／坪。此版沒有經緯度資料；同一路名不保證兩處基地相鄰。預售屋的公開成交資料有發布延遲，且成交中位數不是可保證的議價底價。

觀察列表的燈號與上方三案比較分開計算：以同一建案近三年交易單價的第 25 百分位作便宜界線、中位數作合理參考價、第 75 百分位作昂貴界線；最新一筆單價落在下四分位及以下為綠燈，上四分位及以上為紅燈，其餘為黃燈。少於 5 筆或最新交易已超過三年時不判燈。平均總價包含官方原始交易總價中的車位，平均房屋坪數則扣除車位，兩者不可直接相除當作每坪單價。
