# 購屋紅綠燈

一個以繁體中文製作、免安裝的購屋決策小工具。輸入物件的價格、坪數、自備款與收入後，網站會用紅黃綠燈整理財務壓力與主觀評價，並保留看房前的查核清單。

## 使用方式

直接以瀏覽器開啟 `index.html`，或在本資料夾執行：

```bash
python3 -m http.server 8000
```

然後前往 `http://localhost:8000`。所有資料僅以瀏覽器的 Local Storage 保存，不會傳送到外部。

## 燈號概念

- 綠燈：財務負擔與評價健康，可帶著成交資料進入談價。
- 黃燈：具吸引力但有待確認項目，建議補足貸款、行情或屋況資訊。
- 紅燈：月付壓力、自備款或條件存在明顯缺口，先重新評估。

本工具僅供決策整理，不構成估價、貸款或投資建議。
